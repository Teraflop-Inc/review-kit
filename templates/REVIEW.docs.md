# Review rules: docs and content repo

## What Important means here
- A factual error: wrong command, wrong flag, wrong version, wrong link target.
- Instructions a reader cannot follow as written (missing step, wrong order, missing prerequisite).
- Code samples that would not run or would not produce the stated output.
- Broken internal links, images, or anchors.
- Secrets, internal hostnames, or private data in public content.

## Nits
- At most five, for clarity problems that would trip a reader. Not taste.

## Skip
- Wording preferences, sentence length, and tone, unless the house style below is broken.
- Generated files (sitemaps, search indexes, built HTML).

## Always check
- Commands and code blocks match the current version of the tool they describe.
- House style: American English, and no em dashes used as punctuation.
